# LabOS

LabOS is a dental-laboratory operations application being evolved as a modular monolith with Organization-based tenancy and explicit Authorization V1 capabilities.

## Development

Install dependencies with `pnpm install`, then run `pnpm dev`. Use the focused test and lint commands documented in the relevant plan and [quality baseline](docs/reference/quality-baseline.md).

The repository does not claim an external board as the live source of truth; current repository-visible work is documented in `docs/`.
