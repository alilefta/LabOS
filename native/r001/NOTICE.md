# R001 native codec notices

This application is based in part on the work of the Independent JPEG Group.
The Windows x64 R001 helper statically links libjpeg-turbo 3.2.0's libjpeg API.
Distribute `LICENSE.libjpeg-turbo.md` and `README.ijg` alongside the helper
and retain the build manifest and exact source/binary identities. The pinned
upstream VC x64 installer is verified before extraction and is not committed.
An alternate library, compiler, platform, or build requires new verification
and target-specific containment calibration before use.
