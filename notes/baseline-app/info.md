# What is this dir?

This directory represents a folder for all side effect issues in all routes, or parts of the app, they represent issues that emerged in the base app logic, UI or UX issues, or other kind of issues, and these issues emerged while we are focusing on implementing features, so these issues need be solved according to their priority. For example, an issue like Decimals are getting leaked into the client side, this issue emerged while we testing the invoices issuence and case creation.
